This workspace is the **single consolidated canonical location** on macOS containing all verified, audited, and relevant materials for the **VK7SPORTS** sports apparel platform.

Prior to this consolidation, VK7SPORTS materials were fragmented across 9 separate directories, 3 Git checkouts, multiple Word documents, PDFs, and 150+ multi-agent audit transcripts. This workspace brings together:
1. **The authentic source code implementation** in [`app/`](./app/).
2. **Authoritative business and technical documentation** in [`docs/`](./docs/).
3. **Design references and schemas** in [`design/`](./design/).
4. **Structured sample data** in [`data/`](./data/).
5. **Branding and media inventories** in [`assets/`](./assets/).
6. **The complete 13-document forensic audit suite** in [`audit/`](./audit/).
7. **Traceable historical references** in [`archive-reference/`](./archive-reference/).
